tf-access-map

A read-only dashboard I built for myself to untangle a large access problem: who can change what across a Terraform Cloud estate, how they got that access, and whether the platform is healthy right now.

  • Python
  • HCP Terraform API
  • GitLab API
  • Microsoft Graph
  • Kubernetes
  • HTML / CSS / JS

case study →built for my own use

problem
I had to work out, across thousands of workspaces and hundreds of teams, "who can apply to this, or read its state, and how?" Access chained through SSO groups, teams, projects, and org-wide permissions, and some of it was never written in code. By hand, that was weeks of clicking through a UI.
approach
Read-only collectors with an endpoint allowlist snapshot Terraform Cloud, Git, the identity provider, and the agents' Kubernetes pods, using my own login. A model turns the snapshot into an access graph, and a strict HCL evaluator finds where each grant is declared. One static page shows it all, with no server to run.
outcome
Weeks of manual auditing done in days. Its first run matched the manual numbers exactly. Surfaced access granted outside code, teams that can read all state, and auto-apply workspaces with unprotected deploy branches. Zero writes, no stored tokens, 150+ tests.
